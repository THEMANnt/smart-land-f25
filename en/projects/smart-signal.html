The starting point

The challenge

When one person does not know sign language, everyday conversations can become more difficult. The need is for an assistive tool that makes meaning more accessible while respecting diverse users and the context of communication.

✳

The approach

The solution concept

Smart Signal builds on the sign-language translation idea in the project brief. This concept presents a clear journey from providing a sign to reviewing the suggested meaning and sharing the resulting text.

↗

The goal

Intended impact

Help people understand each other and reduce communication barriers in everyday situations. This is a qualitative goal for the educational concept, rather than a measured result or translation-accuracy claim.

04 / The user journey

A few steps.
A clear destination.

An illustrative scenario explaining how the experience could work. The interfaces are visual concepts, rather than an application running within this page.

  1. 01

    Start with a sign

    The user opens the translation workspace and provides a sign in the imagined scenario.

  2. 02

    Review the meaning

    They read the suggested text and check that it expresses the intended meaning.

  3. 03

    Continue the conversation

    They share or show the text to the other person, then start a new message when needed.
